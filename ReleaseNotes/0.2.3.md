世界修复助手是独立的生存战争模组，用于处理同一位置存在多份静态方块实体记录、导致世界无法进入的问题。

**适用环境：生存战争 2.4 / API 1.9.3.1。** 无其他玩法模组依赖；世界原本需要的模组仍需保留。

本版包含：

- 进入世界前自动检查重叠，发现问题后打开可视化修复界面。
- 实际周围方块半透明显示，冲突位置清晰显示并用红框标记；支持旋转、缩放和隐藏周围。
- 切换记录比较物品等已支持展示的内容，再选择保留哪一份。
- 批量选择内容完全相同的重复记录；内容不同的记录由玩家决定。
- 确认后先备份再修复，完成后可进入世界或立即撤销。
- 弹窗在屏幕中心显示。
- 修复打开动画、滚动和切换记录后，旧帧深度残留导致的方块图标闪烁、缺面问题。
- Remix Icon 操作图标，以及供其他模组扩展内容说明的展示接口。

**安装：** 下载下方的 `WorldRescue-0.2.3.scmod`，安装后重启游戏，再正常进入出问题的世界。升级时替换旧版本，避免同时安装多份。

**修复前请确认：** 未保留记录中的内容会被移除，不会自动合并。“尚无说明”不代表没有数据，所选记录中的未知内容会完整保留。内置备份保存修复涉及的世界状态数据，不等同于完整世界导出；建议额外导出一份完整存档。

本模组不修复缺失模组、损坏地形或任意类型的坏档，也不能阻止其他模组再次制造重叠。第三方自定义加载流程可能绕过检查入口。

验证：28 项逻辑测试通过；在 Windows 游戏宿主中验证了居中布局、连续动画、滚动、切换记录与旋转预览，修复后画面与干净深度的 GPU 输出一致。准备了 1 / 32 / 256 处冲突的测试场景；Android 触屏与复杂第三方方块仍欢迎反馈。

反馈问题时，请附游戏/API 版本、模组列表、报错日志和复现步骤。方便分享时，也可附出问题的存档。

附件 `SHA256SUMS.txt` 可用于校验模组包完整性。
